# O QUE É?

Esse projeto é desenvolvido em Django para demonstrar como é um blog de notícias online.

# Passos Importantes

1 - Instalar os requerimentos do arquivo requirements.txt, para facilitar utilize o comando "pip install -r requirements.txt".
2 - Coloque as informações do seu banco de dados no arquivo .env.EXAMPLE, o docker compose já irá utilizar as variavéis de ambiente que estão lá e o settings.py do projeto também, então é só subir para o docker.
3 - Agora o site poderá rodar com o banco PostgreSQL.
